# Cálculo para todos

Aquí voy guardando páginas web interactivas para estudiar cálculo. Las armo con ayuda de Claude: cada una toma un tema del curso y lo convierte en algo que se puede tocar, mover y explorar en el navegador, en vez de quedarse solo en fórmulas y diapositivas.

La idea de fondo es simple: una curva, un ángulo o un límite se entienden más rápido cuando uno puede jugar con ellos en pantalla que cuando solo se leen.

## Contenido

- **Fundamentos de Cálculo** — páginas organizadas por semana, siguiendo el curso de Fundamentos del Cálculo (UTEC).

Esto se va llenando poco a poco, a medida que avanza el ciclo.
