Vectores III: el producto punto y lo que mide

Dos vectores entran, un número sale: u·v = ux·vx + uy·vy + uz·vz. Ese número te dice el ángulo entre ellos, si son perpendiculares, cuánto de uno cae sobre el otro (la proyección) y cuánto trabajo hace una fuerza. Todas las escenas son en 3D: arrastra para girar, rueda o dos dedos para acercar, y los botones para ver de frente, de lado, desde arriba o en isométrica. Ejes: x celeste, y verde, z mostaza (vertical).

Capítulo 1 · Guía §1–§2 · Producto punto y ángulo

Multiplicar componentes, sumar y leer el ángulo

El producto punto se calcula con las componentes: u·v = ux·vx + uy·vy + uz·vz, y también con la geometría: u·v = |u||v| cos θ. Igualando ambas, cos θ = u·v / (|u||v|). Mueve los puntos y mira cómo el signo del número cambia con el ángulo.

Fórmulas clave Guía §1

u·v = ux·vx + uy·vy + uz·vz · u·u = |u|² · cos θ = u·v / (|u||v|), con 0° ≤ θ ≤ 180°. El resultado es un escalar.

El signo habla Guía §2

u·v > 0 ángulo agudo · u·v = 0 ángulo recto · u·v < 0 ángulo obtuso. Es máximo (|u||v|) con θ = 0° y mínimo (−|u||v|) con θ = 180°.

¡Alerta! Guía §1

u·v es un número, no un vector: no se puede hacer «(u·v) · w». Sí existe (u·v)w, que es un vector paralelo a w. Además u·v = v·u.

Capítulo 2 · Guía §4 · Ortogonalidad

Perpendicular significa producto punto cero

Dos vectores no nulos son ortogonales si u·v = 0. En 2D, para v = (a, b) un perpendicular es (−b, a). En 3D hay todo un plano de vectores perpendiculares a u. Con un parámetro, la condición u·v = 0 es una ecuación que se resuelve.

Fórmulas clave Guía §4

u ⊥ v ⇔ u·v = 0 · en 2D, (a, b) ⊥ (−b, a) · el unitario perpendicular divide entre la magnitud.

Ejemplo resuelto Guía II.A-2c

a = (2, m) y b = (−3, 1): 2(−3) + m = 0 ⇒ m = 6.

Rombo Guía II.A-2d

(u − v)·(u + v) = |u|² − |v|²: las diagonales son perpendiculares si y solo si |u| = |v|.

Capítulo 3 · Guía §5 · Proyecciones

La sombra de un vector sobre otro

La componente escalar de a sobre b es comp_b a = a·b / |b| (con signo). El vector proyección es proy_b a = (a·b / |b|²) b. Lo que sobra, a − proy_b a, es perpendicular a b.

Fórmulas clave Guía §5

comp_b a = a·b / |b| · proy_b a = (a·b / |b|²) b · a = proy_b a + (a − proy_b a).

Ejemplo resuelto Guía Ej. 5.1

a = (3, 4), b = (1, 2): a·b = 11, comp = 11/√5 ≈ 4.919, proy = (2.2, 4.4).

¡Alerta! Guía §5

El orden importa: proy_b a ≠ proy_a b. Y se divide entre |b| para el escalar, entre |b|² para el vector.

Capítulo 4 · Guía §6 · Aplicaciones

Trabajo, rampas, terrenos y bases

El trabajo de una fuerza constante es W = F·d: solo cuenta la parte de la fuerza que va en la dirección del movimiento. Elige una aplicación y carga los problemas de la guía.

Trabajo Guía II.B-6

W = F·d = |F||d| cos θ. Con F = (40, 30) N y d = (5, 0) m: W = 200 J (no 250 J: θ ≈ 36.87°).

Rampa Guía II.B-11

Peso 490 N en 30°: a lo largo de la rampa 245 N, contra la rampa ≈ 424.35 N: son las proyecciones del peso sobre las dos direcciones perpendiculares.

Base ortonormal Guía II.A-5

Si e₁ ⊥ e₂ y ambos son unitarios, las componentes de w son w·e₁ y w·e₂.
