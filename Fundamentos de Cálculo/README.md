# Fundamentos de Cálculo

Páginas interactivas para repasar los temas del curso de Fundamentos del Cálculo, ordenadas según la guía de estudios. Cada archivo HTML se abre directo en el navegador, sin instalar nada; junto a cada uno está el PDF de la guía de esa semana.

## Temas

1. Conjuntos y funciones
2. Función lineal
3. Función cuadrática
4. Operaciones y transformaciones de funciones
5. Composición y función inversa
6. Trigonometría
7. Funciones sinusoidales

Las demás semanas se van agregando aquí a medida que las voy subiendo.
